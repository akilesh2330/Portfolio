## ✨ Features

- **Cyber Glassmorphism Design**: High-end aesthetics featuring frosted glass panels, neon gradient accents, and responsive typography (Inter, Outfit, Fira Code).
- **Interactive Particle Space Canvas**: Dynamic HTML5 canvas with responsive background particle animation.
- **Interactive Interactive Terminal**: Embedded command-line interface simulator that responds to terminal commands (`help`, `about`, `skills`, `projects`, `contact`, `clear`).
- **Interactive Custom Cursor**: Glowing neon ring cursor with trailing physics and hover reaction effects.
- **Categorized Project Showcase**: Instant filtering by category (*All*, *AI & ML*, *Computer Vision*, *Web Development*, *Game Dev*) with modal preview popups.
- **LeetCode & Core CS Highlights**: Showcases algorithmic problem solving, time/space complexity analysis, and engineering fundamentals (DBMS, OS, OOP, Computer Networks).
- **Contact Form & Quick Connect**: Direct email, phone, location, and social links integration.
- **Mobile Responsive**: Fluid layout tested across mobile, tablet, and desktop viewports.
- **SEO & Performance Optimized**: Complete Open Graph, Twitter Cards, meta tags, and structured JSON-LD schema.

## 🚀 Getting Started

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akilesh2330/Portfolio.git
   cd Portfolio
   ```

2. **Open with any local development server or browser:**
   - **VS Code Live Server**: Right-click `index.html` and select **"Open with Live Server"**.
   - **Python Simple Server**:
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000` in your web browser.
